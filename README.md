# Aica Appliance Error

An entry for make.fun's **The Funniest Honest Appliance Error** competition: one line, at most 200 characters — the funniest honest error message an appliance could show.

The line is a washing machine reporting a real fault in its own flat voice: the drain is blocked, and the culprit is the sock you lost in March, sitting in the filter and holding the water hostage. The joke comes out of the truth of the fault, not a pun bolted on.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt`. Python standard library only, deterministic — running it twice produces byte-identical output.
